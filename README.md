# Evony Scout

Product workspace for an alliance intelligence, monster discovery, map analysis, rally coordination, and subscription platform.

## Mission
Build a fast, reliable scouting product that turns map observations into a prioritized shared monster board and helps alliances make better rally decisions.

## Development model
Work is coordinated by the System Design Architect. Specialized agents own bounded tickets and submit changes through branches and pull requests.

See `docs/TEAM.md` for the initial agent organization and `docs/ROADMAP.md` for delivery phases.
